# 电池

电池对于SHM节点来说是必不可少的组件。它为节点提供电力，使其能够在没有外部电源的情况下运行。选择合适的电池对于确保节点的可靠性和性能至关重要。对于电池，我们需要在容量、放电率、尺寸和安全性等方面进行权衡。

## 电池型号

目前我们选用18650锂离子电池作为SHM节点的电源。这种电池具有较高的能量密度和较长的使用寿命，适合我们的应用需求。

![18650](18650.png){width=100%}

## 电池盒

出于设计考虑，我们选用可以自由拼接的电池盒进行设计组装。电池盒的设计允许我们根据需要增加或减少电池数量，以满足不同的容量需求。同时，电池盒还提供了良好的保护，确保电池在使用过程中安全可靠。
