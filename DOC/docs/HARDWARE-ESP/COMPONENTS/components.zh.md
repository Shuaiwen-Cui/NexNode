# 元件选型

## 主控

### 核心模组ESP32S3

出于简单考虑，本项目主控采用ESP32S3模组而非裸芯，候选的模组有：

| 模组型号         | 天线类型          | FLASH     | PSRAM   | 
| ----------------| ---------------- | --------- | ------- |
| ESP32S3-WROOM-1 | PCB天线/IPEX天线  | 16MB      | 8MB    |
| ESP32S3-WROOM-2 | PCB天线           | 32MB      | 16MB   |
