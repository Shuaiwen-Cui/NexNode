## 螺丝螺母

螺丝规格：M2.5x5，即螺丝直径为2.5mm，长度为5mm。
螺母规格：M2.5*4*4，即螺母内径为2.5mm，外径为4mm，高度为4mm。

每个节点可配约100个螺丝和100个螺母，具体数量可根据实际安装需求进行调整。

## 排针/排母/跳线帽/连接导线

本项目每个节点还需要一些排针、排母、跳线帽和连接导线来连接PCB和其他组件，但是由于这些零件相对容易购买，下方仅列出规格，读者可自行在当地市场购买，注意排针排母针脚间隔为2.54mm：

- 对于核心板，需要4个2x5p排针,1个1x2p直排针用来构成测量电压电路，1个1x2p弯排针用来控制电源指示灯通断，还需要一个跳线帽来配合控制电源指示灯的通断。
- 对于扩展板，需要4个2x5p排母。

其他还需要一些工具，比如螺丝刀，焊枪，热风枪等，焊台，热熔胶枪，以及一些常用的电子工具和测试工具，如万用表，示波器等，这些工具的购买链接可能会因为地区和品牌的不同而有所差异，读者可以根据自己的需求和预算在当地市场寻找合适的工具。
