## 物理结构

我们采用三块板的设计，分别为：

- 扩展板：提供各种接口和扩展功能，支持多种传感器和执行器的连接。
- 主控板：搭载ESP32S3芯片，负责系统的核心处理和控制，同时也提供常见的基础功能如存储和基本状态反馈。
- 电源板：负责为整个系统提供稳定的电源供应，同时支持电池供电和电线供电两种方式，并具备电源管理功能以优化能耗和延长电池寿命。（该板直接采购第三方的电源管理板，后续可能会根据实际需求进行定制设计）
