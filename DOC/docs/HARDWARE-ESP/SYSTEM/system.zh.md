## 物理结构

我们采用三层板的设计，分别为：

- 顶层-扩展板：提供各种接口和扩展功能，支持多种传感器和执行器的连接。
- 中层-主控板：搭载ESP32S3芯片，负责系统的核心处理和控制，同时也提供常见的基础功能如存储和基本状态反馈。
- 底层-电源板：负责为整个系统提供稳定的电源供应，同时支持电池供电和电线供电两种方式，并具备电源管理功能以优化能耗和延长电池寿命。（该板直接采购微雪电子的电源管理板，后续可能会根据实际需求进行定制设计）

## 系统架构

系统架构分为以下几个部分：

### 主控系统

- 微控制器芯片或模组 - 基于ESP32S3

### 感知系统

- 温湿度
- 加速度
- 声音 (可选)
- 图像 (可选)

### 通讯系统

- WIFI
- 蓝牙 - 低功耗
- 2.4G无线通信
- 蜂窝移动网络 - 低功耗（Cat-M1/NB-IoT） (可选)

### 执行系统

- LED/RGBLED
- 蜂鸣器  (可选)
- 显示屏  (可选)

### 电源系统

- 电池/电线供电
- 电源管理

### 外壳系统

- 外壳
- 挂载系统设计
