# 数字温湿度传感器-DHT11

![](DHT11.jpg)

!!! info "Information"
    DHT11是一款常用的数字温湿度传感器，具有成本低廉、易于使用的特点，适合用于基本的温湿度测量应用。它通过单线通信协议与微控制器进行数据交换。

## 技术规格

| 特性          | 说明                             |
| ------------- | -------------------------------- |
| 测量范围      | 温度：0°C至50°C，湿度：20%至90% RH |
| 精度          | 温度：±2°C，湿度：±5% RH         |
| 分辨率        | 温度：1°C，湿度：1% RH         |
| 电源电压      | 3.3V至5V                        |
| 通信接口      | 单线数字信号                     |
