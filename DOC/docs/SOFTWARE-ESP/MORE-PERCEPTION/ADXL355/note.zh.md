# ADXL355 数字加速度计

## 简介

加速度测量是许多嵌入式系统中的常见需求。ADXL355 是一款高精度、低功耗的三轴数字加速度计，适用于各种应用场景，如运动检测、倾斜测量和振动监测。

## 技术规格

| 参数      |  规格                     |
|-----------|--------------------------|
| 测量范围  | ±2g、±4g、±8g              |
| 分辨率    | 20 位                     |
| 采样率    | 0.1 Hz 至 4000 Hz         |
| 接口      | SPI、I2C                  |
| 工作电压  | 2.0V 至 3.6V              |
| 工作温度  | -40°C 至 +85°C            |
