# 核心功能模块/组件列表

!!! info "说明"
    核心功能开发着重于开发通用性的节点功能，至于专用于某些应用或者场景的功能我们放到扩展功能开发中进行介绍。以下是核心功能模块/组件列表，以推荐开发顺序呈现：

| 范畴          |  功能             |  组件/模块           |  备注            |
| ------------- | ----------------- | -------------------- | ---------------- |
| 执行          | LED 指示灯控制       | node_led            |  用于反馈节点状态     |
| 执行          | RGB 指示灯控制       | node_rgb            |  用于反馈节点状态     |
| 控制          | 外部中断           | node_exti           |  用于外部中断处理和响应 |
| 控制          | 定时器             | node_timer          |  用于周期性任务后台处理 |
| 控制          | 实时时钟           | node_rtc            |  用于时间管理和定时唤醒 |
| 控制          | 随机数发生器       | node_rng            |  用于生成随机数       |
| 控制          | I2C 总线          | node_i2c            |  用于连接 I2C 设备    |
| 控制          | SPI 总线          | node_spi            |  用于连接 SPI 设备    |
| 执行          | SD 卡存储         | node_sdcard        |  用于数据存储        |
| 通信          | WIFI 无线通信     | node_wifi          |  用于无线网络连接     |
| 通信          | 物联网通信        | node_iot           |  用于物联网数据交互    |
<!-- | 执行          | LCD 显示屏       | node_lcd            |  用于显示信息        | -->
